# Nohely Studio Nails - Sitio web

Sitio web responsive creado a partir del catálogo PDF.

## Cómo abrirlo
1. Descomprime el archivo ZIP.
2. Abre `index.html` en el navegador.

## Publicarlo gratis
Puedes subir la carpeta a:
- Netlify
- Vercel
- GitHub Pages

## Personalización rápida
- Textos y enlaces: `index.html`
- Diseño y colores: `styles.css`
- Interacciones: `script.js`

El botón de WhatsApp está configurado con el número visible en el catálogo.
